# 進行計画

最初のマスタープロンプトで決めた **Phase 0 〜 10** を、いまの決定に合わせて更新したもの。
フェーズの番号と区切りは原文のまま。中身だけ、Phase 0〜2 で決まったことを反映しています。

## 守るルール

原文の「Claude Code Working Rules」24項目を、いまの言葉でまとめ直したもの。

### 進め方

- **フェーズを飛ばさない。** 各フェーズの終わりで**必ず停止**する
- 停止するときは5つを報告する — **何をしたか / 変更点 / 確認できるもの / 次の予定 / 判断が必要なこと**
- **明示的な承認なしに次へ進まない。** 「ついでに次も作っておきました」は禁止
- 一気に全部作らない。次フェーズの実装を先回りしない
- 大きな仕様変更を、理由を説明せずにしない

### プロダクト

- **特定の業種にハードコードしない**
- **Chat 中心の UI にしない。** 主役は「会社が動いている状態」
- **偽の進捗を出さない。** 画面の状態＝バックエンドの状態
- **重要な情報を会話履歴だけに保存しない。** 決定は構造化して残す
- **成果物を会話から分離する**
- **高度なAI設定（モデル・思考量）は一般ユーザーから隠す**
- AI社員の人数より **Work の完了**を優先する
- セキュリティとプライバシーを速度のために犠牲にしない
- **外に出る道具（メール送信・公開・デプロイ・支払い）は、必ず社長の Approval を挟む**。
  調査・下書きは自動でいい。取り消せない一歩だけ、人が押す

## 横断 — 自分から動く会社（Phase 7〜11 のあと）

チャットボット（Grok bot 等）は聞かれるまで黙っている。**会社は先に言う** — ここが対抗軸。

| | |
|---|---|
| やったこと | **朝の報告** — その日はじめて器を開いたとき、きのうの動き（実行・要確認・判断待ち・停止）を統括AIが1通にする（`morningBrief`。日付で重複を止め、動きが無い朝は黙る）／ **ポンプ** — 開いている画面が次の queued を起こす（見ていないところで料金だけ増えない）／ ダミーデータを「実際に使いそうな人」の物語に揃えた（会社名の名札をやめた） |
| 再点検①（同時操作） | 実行の二重起動（タブ2つで同じタスクが二度走る）→ `startRun` を atomic claim に ／ 差し戻し・フェーズ承認の二度押しで二重書き込み → review のものだけ動かす ／ 朝の報告と採用の一意性を 0015 の一意 index でDB側でも守る ／ 失敗した実行も使ったぶんは記帳 ／ 朝の「その日」は社長の側の日付で数える |
| 再点検②（回復性） | サーバーが途中で入れ替わると実行が running のまま固まり**ポンプが永久に止まる** → `reclaimStalled`（10分で失効。はじめてなら積み直してもう一度、二度目は blocked ＋ エラー通知）／ FK の覆い index 31本 ＋ RLS の行ごと再評価1本（0016） |
| 標準スキルと学び | **標準スキルは見せる**（builtin 3枚を播種。切れるが消せない・「標準」タグ）／ 実行が有効なスキルを最大2枚読み、used_count が進む ／ **学び** — 社員が `note_learning` で書き溜め、次の実行の依頼文に載る。設定ペインで見える・消せる。**ルールには自動で書かない** |

| 入口とセキュリティを整える（2026-08-25） | 社長の指示「新規登録なのかログインなのかちゃんと区分したい／パスワードを忘れたときも／パスワードは大文字小文字記号が必要に」。**入口は1つの姿しか無く、はじめての人と2回目の人が同じ画面**にいた。**3つの姿に分けた** — `login` / `signup` / `forgot`（`?mode=` で URL に持つ。切り替えは `history.replaceState` でサーバーに行かない）。**メールのリンク（マジックリンク）は畳んだ** — 「忘れたときに届くメール」が再設定で足りるので、メールで入る道が2本あった。**忘れたときの姿だけ Google を出さない**（Google の人にパスワードは無い）。**パスワードの決まりは `lib/auth/password.ts` の1か所**（10文字・大文字・小文字・数字・記号。満たしたところから緑、満たすまで送るボタンは灰色）で、**記号の並びは Supabase が数えるものと同じ** — 片方だけ厳しいと、画面で断られたものが API では通る。**ただし画面の決まりはUXであって、セキュリティそのものではない**（匿名鍵はブラウザに配られているので、画面を通さず認証API を叩けば弱いパスワードでも作れる）。**本当に止めるのはダッシュボードの Minimum password length ＋ Required characters** で、手順は `docs/RUNNING.md`。**画面だけ直して「守った」と言わない**。セキュリティで直したもの: **メールの総当たりを助けない**（「そのメールは登録されていません」と言わない。ログイン失敗はいつも同じ1行）／ **オープンリダイレクト**（`/auth/callback` の `?next=` をそのまま渡すと `//evil.example` で他所へ送れた → `/` で始まる素の path だけ通す）／ **入っている人に入口を見せない**（`/login` → `/home`。ただし `/auth/*` は素通しのまま — 再設定はセッションを持ったまま開く画面なので、弾くと自分のパスワードを変えられなくなる）／ **再設定は2回打たせる**（見えない文字を1回で決めさせると、打ち間違えたまま締め出される）／ **リンクを踏んでいない `/auth/reset` は正直に断る**。**確認メールが要るかどうかは Supabase が決める**ので、画面はどちらでも正しく振る舞う（`/api/health` の `signup.confirm` で見える）。検査は `tools/check/login.mjs`（12項目・3つの姿を1つずつ押す）＋ layout に3画面 |

## 機能候補の判断（2026-08-24・見送りの台帳）

出された候補12件のうち、**導入した5件**は上の横断の表にある（会社の記憶 / Agent Memory=学び＋差し戻し / 成果物の版 / runs.model / ⌘K）。
**見送った7件**は「悪い案だから」ではなく「順番が違うから」。理由ごと残す:

| 候補 | 判断 | 理由 |
|---|---|---|
| Task Dependencies（並列実行） | 見送り | `task_deps` の器は 0001 からある。いまの逐次ポンプは「依存＝直列」の正しい近似で、並列化は**開いている画面の課金が N 倍**になる話とセット。統括AIが依存を書くようになってから |
| Agent Activity / Run History | 既にある | runs / run_steps / decision_refs / audit_events が Action Log そのもの。画面はデスクとタスクの歩みが読む |
| Model Router 高度化（難易度で自動選択） | 見送り | 実モデルの品質・原価の実測が無いのにルーティングを作るのは早い。器はそろった — **2026-08-25 に「社員ごとにモデルと深さを選ぶ」が本物になった**（`lib/ai/catalog.ts` ＋ `agent_prefs`）ので、自動で選ぶ側を足すときは、この一覧と設定の上に乗る |
| AI Governance（ZDR モード） | 半分導入 | Run ごとの Model / Cost / Tier の記録は入れた（0018）。ZDR・provider 固定は OpenRouter の `provider` 指定で可能だが、**鍵が無いと検証できない** — Phase 11 の宿題のまま |
| Permissions / Approval 階層 | 原則だけ記録 | いまの道具は全部「書き残す」系で、外に出る道具（メール送信・公開・支払い）が無い。**外に出る道具を足すときは Approval 必須** — この原則を先に固定する（下の「守るルール」に追記） |
| Routines（定期業務） | 見送り | 「見ていないところで料金だけ増えない」（ポンプの決めごと）と真っ向からぶつかる。常時実行は Cloudflare（Cron / DO）に出るときに、専用ロールの設計と一緒に。朝の報告が最初の Routine の形 |
| Cloud Workspace / Sandbox | 見送り（MVP後） | 候補の文のとおり大型機能。Web検索（OpenRouter の web プラグイン）だけは既にあり、鍵と課金設定で有効化できる |
| **複数社（memberships）** | **見送り（2026-08-24・社長の判断）** | いまは**会社は1つだけ**。器（`accounts` と全ポリシーの `account_id = private.current_account_id()`）はそのままなので、入れるときポリシー28本は無変更で足せる。**押せる顔をやめた** — パンくずの根から ⌄ と「会社を追加」を外して素の文字にした（切り替える先も増やす道も無いのに押せるのは、「押しても何も起きないものを置かない」に反する）。入れるときは `memberships` ＋ `current_account_id()` の書き換えを認証と一緒に。そのとき **トライアル枠は人に1回・2社目からは有料**（会社を作り直すだけで枠が湧かないように） |
