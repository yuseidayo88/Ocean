# 09 — 行き先の地図

> 判断ログ（2026年8月）。Phase 4 のレビューで
> 「何にリンクするか自体を決めずに UI をデザインした感がある」と指摘されて作った。

## 何が問題だったか

23画面ぶんの見た目を作ったが、**画面と画面のつながりを一度も書き出していなかった。**
実装には `<Link>` が **10個**しかなく、押せる顔をしているものの大半がどこにも行かなかった。

## 3つの決めごと

### 1. 開いている1件は URL に持つ

`?open=<id>`。こうすると:

- **別の画面から「その1件」へ直接飛べる**（`/tasks?open=tk-price`）
- トップバーの **‹ › が本当に効く**（開く・閉じるも履歴になる）
- リンクを人に渡せる

### 2. 行き先は3種類しかない

| 種類 | 何が起きる | 例 |
|---|---|---|
| **同じ画面で開く** | 右パネルがその1件で開く | 一覧の行 |
| **別の画面のその1件へ** | 画面が変わり、開いた状態で着く | 担当 → `/team?open=e-dev` |
| **別の画面の一覧へ** | 画面が変わるだけ | すべて表示 → `/deliverables` |

### 3. 行の中のリンクは行の開閉を邪魔しない

一覧の行は押すと開く。その行の中にある担当名や Work 名は**別の画面へのリンク**なので、
`stopPropagation` して行の開閉と食い合わないようにする。

## 地図

### 左レール（どこからでも）

`ホーム → /home` `通知 → /inbox` `Work → /work` `タスク → /tasks`
`成果物 → /deliverables` `メンバー → /team` `決定事項 → /decisions`
チャットの各行 → `/chat/<id>` ／ ＋ → `/chat/new`
開いている Work → `/work/<id>`

**「すべて見る」はレールに入りきらないときだけ出す。** 3件しかないいまは出さない
（行き先のないリンクを置かない）。増えたらチャット一覧の画面が要る

### ホーム

| ビュー | 押せるもの | 行き先 |
|---|---|---|
| オフィス | 絵（輪・Work 名・社員の球・統括AI） | **どこにも飛ばない**（下のAI社員の一覧と対で光る） |
| | 下のAI社員のカード | `/team?open=<社員>` |
| デスク | レーンの見出し | `/team?open=<社員>` |
| | 「決める」 | `/decisions?open=dec-price` |
| | 足もとのタスク名 | `/tasks?open=<タスク>` |
| 進捗 | Work のレーン | `/work/<id>` |
| | ◆ とラベル | `/decisions?open=dec-price` |
| | 担当の粒 | `/team?open=<社員>` |
| ワークフロー | フェーズ / Work 名 / 成果物 / 判断 | **盤面から出ない**（`?of=<work>` でその鎖だけ残す） |
| | 盤面そのもの | 移動・拡大縮小（Figma と同じ。ホイール / ⌘＋ホイール / つまむ / ダブルクリックで全体） |

### 一覧

| 画面 | 押せるもの | 行き先 |
|---|---|---|
| タスク | 行 | 同じ画面で開く |
| | Work 列 | `/work/<id>` |
| | 担当 列 | `/team?open=<社員>` |
| 成果物 | カード | 同じ画面で開く |
| | 作った人 | `/team?open=<社員>` |
| 決定事項 | 行 | 同じ画面で開く |
| | 根拠の「収益モデル比較レポート」 | `/deliverables?open=d-rev` |
| | 「収益シミュレーションが始まる」 | `/tasks?open=tk-sim` |
| メンバー | 行（在籍・まだいない人） | 同じ画面で開く |
| | まだいない人の「採用する」 | 行き先なし（その場で採る） |
| | スキルの行 | `/skills?open=<ファイル>` |
| 通知 | 行 | 同じ画面で開く |
| | ぶら下がった成果物 | `/deliverables?open=<成果物>` |
| スキル | 行 | 同じ画面で開く |

### Work

| 押せるもの | 行き先 |
|---|---|
| フェーズの行 | `/tasks`（そのフェーズのタスクへ） |
| いま動いているもの（タスク） | `/tasks?open=<タスク>` |
| いま動いているもの（成果物） | `/deliverables?open=<成果物>` |
| 成果物のカード | `/deliverables?open=<成果物>` |
| すべて表示 | `/deliverables` |
| 右パネルの「決めたこと」 | `/decisions?open=<決定>` |
| 右パネルの AI社員 | `/team?open=<社員>` |
| 入力欄「この Work について統括AIに相談する」 | `/chat/<この Work のスレッド>` |

### 入口（Case B / D）

```
/start ─┬─ まだ決まっていない → /discovery → /discovery/result → この案ではじめる → /work/new
        └─ すでに事業がある   → /import    → 診断する          → /diagnosis → この Work を立てる → /work/w-japanese/plan
/work/new → （書くと計画が立つ）→ /work/<id>/plan → 承認して始める → /work/<id>
```

## まだ行き先が無いもの（作らない、と決めたもの）

置いてあるが押しても何も起きないもの。**押せる顔をやめる**か、Phase 5 で中身と一緒に作る。

| もの | どうするか |
|---|---|
| 検索（⌘K） | Phase 5 以降。いまは押せる顔だけ残す |
| 絞り込み | 同上 |
| 盤面の拡大縮小・ミニマップ | 盤面の中の操作。画面遷移ではない |
| スキルの ⬇ ✏ 🗑、＋追加 | 書き込みなので Phase 5 |
| 「一時停止」「決め直す」など行動の行 | 書き込みなので Phase 5 |
| チャット一覧 | スレッドが増えたら要る。いまはレールで足りる |
