# 16. 公開する（LP の出し先）

2026-08-27。社長の「他のやつから順にお願いします」の③。

## 何が無かったか

AI社員は LP を書ける（`page` の成果物。→ `docs/design/12-outputs.md`）。
でも**出し先がなかった** — 書いたものはアプリの中にしかなく、
⬇ で `.html` を落として、自分でどこかに上げるしかない。

一人社長にそれをやらせるなら、**作れたことに意味がない**。
「持ち出せない成果物は、無いのと同じ」（2026-08-25）の、その先。

## 出し先はこのアプリ自身

`/p/<slug>`。**外の業者の鍵を待たない。**

Cloudflare Pages や Vercel に出す道も考えたが、どちらも
`CLOUDFLARE_API_TOKEN` / Vercel の鍵が要る — この環境からは出られないし、
**鍵が入るまで動かないものは、入るまで嘘**になる。
自分のところに出せば**いま動く**し、Cloudflare でも Vercel でも同じに動く。

外の出し先（独自ドメイン・Cloudflare Pages）は、要るようになってから足す。
そのとき `published_pages` の行はそのまま使える。

## 決めたこと

- **公開は社長が押したときだけ。** 外に出る道具は Approval 必須
  （→ `docs/PLAN.md` 守るルール）。AI社員の道具にはしていないし、
  **統括AIも自分では公開できない**
- **承認済のものだけ。** 見ていないものを世に出さない
  （要確認 ＝ あなたが成果物を見る、の意味がなくなる）
- **一度だけ確かめる。** 押す → 何が起きるかを読む → もう一度押す。
  下げても誰かの手もとには残りうるので、そこも言う
- **出したのは押した時点の中身。** あとから直しても勝手には変わらない。
  もう一度押すと入れ替わる — **行き先（slug）は変わらない**
  （URL を配ったあとで変えない）
- **下げても行は消さない**（`revoked_at`）。いつ出して、いつ下げたかが残る

## script は落とす

出すのは**自分のオリジン**なので、置いたままの script は
**このアプリの名前で**走る。LP に script は要らないので落とす。

- 落とすもの: `<script>` `<iframe>` `<object>` `<embed>` `<noscript>` /
  `onclick=` の類 / `javascript:` と `data:text/html` の行き先 /
  `<meta http-equiv="refresh">`
- **落としたことは社長に言う**（「script などの動くもの を落としました」）。
  黙って中身を変えない
- **落とし漏れても走らないように、CSP でも止める**（`script-src 'none'`）。
  絵・書体・面は外から来ていいので、そこは開ける

`page.tsx` ではなく **route handler** で素の HTML を返す。
画面にすると器（`<html>` と全体の CSS）が付いてきて、社長の LP と喧嘩する。

## 隠れた場所ではない

`published_pages` は**この製品で唯一、誰でも読める表**。
ほかの28本のポリシーは `account_id = private.current_account_id()` だが、
ここは公開したものを置く場所なので、そこを守っても意味がない
（守ったら、公開したページが誰にも見えない）。

そのかわり:
- 入るのは社長が押したときだけ・承認済のものだけ
- 下げれば公開の側からは読めない（`revoked_at`）
- slug に**短い符号**を足すので、隣の会社の `/p/lp` を当てずっぽうで開けない

**それでも「秘密の URL」ではない。** 画面でもそう書く
（「出すと、この会社の外の人が URL で読めます」）。

## 検査

`tools/check/publish.mjs`（13件）— LP を作る → 承認する前は出せない →
承認 → 一度確かめて公開 → `/p/<slug>` がログイン無しで開く →
**script は落ちている** → 下げると 404 → もう一度出すと同じ URL。

**決め打ちのプロバイダは、本番と同じ壊れ方をする** — 頼まれてもいないのに
LP に `<script>` と `onclick` を書く（本物のモデルがそうする）。
行儀よく書くと、落としているかを検査できない。

## まだやっていない

- **独自ドメイン**（`www.じぶんの会社.com`）。要るようになってから
- **書き換えの追随**（成果物を直したら自動で出し直す）。
  いまは押したときだけ — **勝手に外へ出さない**ほうが正しい
- **どれだけ読まれたか。** 数えるなら、何をどこに残すかを先に決める
