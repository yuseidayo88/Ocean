Executive Context Panel Workspace
EXECUTIVE — 3 STATES
① Dock — 1行の入力。Workspaceが主役のまま短い指示。
② Expanded — Workspaceを残したまま会話履歴を展開。
③ Chat Focus — Workspace / Panelを一時収納。検索・Phase別Jump。
CONTEXT PANEL — 3 STATES（案A）
Normal — 70 / 30。作業状態を主に、文脈を参照。
Split — 50 / 50。Workspaceと成果物を並べて比較。
Focus — Browser / Report / Codeを最大化。閉じるとNormalへ復帰 ↩
NEW WORK — CENTER STAGE → DOCK TRANSITION
① New Work — Executiveが中央に。目的 → 質問 → 提案。
② Plan Review — Goal / Roadmap / Team / First Tasksを承認。
③ Start Work — Executiveが下部Dockへ移動し、Workspaceが稼働画面へ。
